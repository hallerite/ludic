# Micro-Batching Notes

## Current Design
- BatchSource returns a macro-batch (SAWBatch).
- Trainer calls `collate_micro_batches(...)` to bucket + split by token budget.
- Each micro-batch is padded to its local max length; loss is scaled by
  `micro.num_items / total_items` to preserve a macro-batch mean.
- User-facing knobs are now:
  - `rollouts_per_update` (macro batch size in rollouts)
  - `max_seq_len` (max tokens per sample)
  - `micro_token_budget` (max padded tokens per micro-batch)
- Recommended defaults:
  - `max_seq_len=1024`
  - `max_completion_tokens=512`
  - `micro_token_budget=8192` (8 × 1024)

## Resolved
- Overlong samples are truncated to `max_seq_len` during micro-batching and
  tagged with `seq_len_truncated`, `seq_len_original`, `seq_len_retained`, and
  `seq_len_retained_frac` in metadata.
- Cross-rank stat reduction now weights by `num_samples` (when present) instead
  of averaging per-rank means, avoiding bias with uneven batch sizes.
- A `default_reducers()` helper now logs `completion_truncated_rate`,
  `incomplete_completion_rate`, `seq_len_truncated_rate`, and
  `seq_len_retained_frac` when those fields are present (opt-in).

## Calibration Script Review (scripts/calibrate_micro_batch.py)
Looks good overall: it loads a real model (optional FSDP2), builds synthetic
SAWBatches, runs `collate_micro_batches`, and reports time + peak memory.
Potential improvements to consider after GPU testing:
- Add a mode to sample real length distributions (e.g., from JSONL rollouts) so
  the padding ratio reflects target data, not uniform random lengths.
- Report actual padded token counts per micro-batch (and padding ratio), not
  just the configured `micro_token_budget`.
- Expose a flag to vary prompt vs completion ratio across a distribution (not
  a single `action_ratio`).
- If we keep micro-batch weighting by item count, optionally report both
  sample-weighted and token-weighted metrics for clarity.

## Train Script Adaptation Status
All existing training scripts appear updated to:
- accept `--rollouts-per-update`, `--max-seq-len`, `--micro-token-budget`
- pass `max_seq_len` + `micro_token_budget` into `TrainerConfig`
